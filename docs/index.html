Link

~/.claude is not a repo: Claude Code's runtime state, plus one symlink into this checkout per item it reads.

mise run link (.mise/tasks/link) links each rules/*.md, skills/*/ and workflows/*.js into a real directory of that name, so another setup's items sit beside ours, and each user/ file at the top: CLAUDE.md (the user memory; the root CLAUDE.md is the project's, importing AGENTS.md) and settings.json. A new item is live only after a run. The mod loads in place, so it is not linked.

  • never overwrites — an item path, or one of the three directories, that is a real file or a foreign link is drift: and left alone; merge it by hand, then re-link.
  • prunes its own — a link into this checkout that no item claims is unlink:, removed; one to a moved item is re-pointed. Anything else is not ours and not reported.
  • --check changes nothing, reports missing: / stale: instead, and exits 1 on anything but ok; a plain run exits 1 only on drift.

Doctor

Read-only and deterministic, no model calls; the weekly routine runs it and parses its lines.

mise run doctor (.mise/tasks/doctor.ts) checks the live setup: settings.json and ~/.claude.json parse, link --check is clean, the install is native and current, each MCP server's command resolves, the always-loaded memory (CLAUDE.md plus every rule without paths:) stays under 24000 chars, each skill's frontmatter names name and description, and no hook's median run is slow over the last 30 days of transcripts.

  • one line per finding — ok:, broken:, unused: (an MCP server, plugin or skill with no use in its window, sorted), note:; then doctor: N broken, M unused. Exit 1 only on broken.
  • prints no secrets — a file that fails to parse is named with jq's position alone, and the checks reading it are skipped; an MCP server's env and headers are never read.

Show

How an agent puts a decision in front of the owner and talks with him through it: skills/show/, its contract the skill's SKILL.md.

The catalog (skills/show/catalog.tsx): every card also takes id, title, meta?, and gets options, a message box, its own Send and a thread.

  • no browser streams — live changes ride WebSockets, hud's and show's; never an EventSource or a streamed fetch, which Chromium caps at six per host:port across every tab. A test fails on either in the client.
  • disk is the truth — ${XDG_STATE_HOME:-~/.local/state}/show/; a kill loses nothing a restart cannot re-read. One instance by flock, every stop signal drains, launchd (io.jlg.show) keeps it up once show setup has run.

The subether mod

settings.json wires no hooks; the mod does. Its design is subether.html, its contract plugins/subether/README.md.

subether, the from-scratch successor of perpetual (uninstalled 2026-11-06), seeds a session's first prompt with sandman recall, which also marks its start, and shows that and the agent's later pulls in a pane, guards Bash and *.yml writes by the house rules, logs every tool call and typed prompt, keeps the gauge row and five-hour window clock, and hands each ending session to sandman take; the shift band is to come. The repo is the local marketplace jgeschwendt (.claude-plugin/marketplace.json), listing subether and monitor (skills/monitor).

Gate

hk's pre-push hook (hk.pkl), one step.

bun run test (scripts/test.ts) runs every step at once — fmt, lint, tsc, the unit tests (link, doctor, /end and /delete), show's tests held at 100 % line and function coverage, the mod's validate and suite — then the stele gate.

ci.yaml runs the same gate, the claude CLI installed at a pinned version, on push to main, pull requests and the merge queue; never stele build, the lock's sole writer.
