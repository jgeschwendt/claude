Link

~/.claude is not a repo: Claude Code's runtime state, plus one symlink into this checkout per entry it reads.

mise run link (.mise/tasks/link) links CLAUDE.md, rules/, settings.json, settings.local.json and skills/, then compares the installed mod with the trunk's. On the perpetual/rewrite branch that compare is broken until cutover: it still reads plugins/perpetual/.claude-plugin/plugin.json.

  • never overwrites — an entry that is a real file or a foreign link is drift: and left alone; merge it into the checkout by hand, then re-link. Only a missing entry is linked.
  • prunes its own — a link into this checkout for an entry no longer listed is unlink:, removed.
  • reports the mod — differs: when the user-scope perpetual install is not the trunk's plugin.json version, missing: when it is not installed.
  • --check changes nothing, reports missing: / stale: instead, and exits 1 on anything but ok; a plain run exits 1 only on drift or a mod line other than ok.

The subether mod

settings.json wires no hooks; the mod does. Its design is subether.html, its contract plugins/subether/README.md.

subether, the from-scratch successor of perpetual (uninstalled 2026-11-06), attaches sandman recall to a session's first prompt and shows it in a pane, guards Bash and *.yml writes by the house rules, logs every tool call, judges typed prompts and asked tool calls with a System One model, and keeps the gauge row and five-hour window clock; the docket hooks, the session-end take and the shift band are to come. The repo is the local marketplace jgeschwendt (.claude-plugin/marketplace.json), listing subether and monitor (skills/monitor).

Gate

hk's pre-push hook (hk.pkl), one step.

bun run test (scripts/test.ts) runs every step at once — fmt, lint, tsc, the unit tests (link, /delete, /dissolve), monitor-github's selftest, the mod's validate and suite — then the stele gate.

ci.yaml runs the same gate, the claude CLI installed at a pinned version, on push to main, pull requests and the merge queue; never stele build, the lock's sole writer.
