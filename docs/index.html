Link

~/.claude is not a repo: Claude Code's runtime state, plus one symlink into this checkout per entry it reads.

mise run link (.mise/tasks/link) links CLAUDE.md, rules/, settings.json, settings.local.json and skills/, then compares the installed mod with the trunk's.

  • never overwrites — an entry that is a real file or a foreign link is drift: and left alone; merge it into the checkout by hand, then re-link. Only a missing entry is linked.
  • prunes its own — a link into this checkout for an entry no longer listed is unlink:, removed.
  • reports the mod — differs: when the user-scope perpetual install is not the trunk's plugin.json version, missing: when it is not installed.
  • --check changes nothing, reports missing: / stale: instead, and exits 1 on anything but ok; a plain run exits 1 only on drift or a mod line other than ok.

The perpetual mod

settings.json wires no hooks; the mod does. Its behaviour is specified in plugins/perpetual/README.md.

  • session hooks — runs sandman's (recall, report, take) and docket --hook from ~/.local/bin; a missing binary, timeout or non-zero exit adds nothing and never blocks.
  • guards — denies the Bash commands the house rules forbid (pkill -f, tree discards, force pushes, git stash, git clean) and writes to *.yml, trailing each denial to sandman; pins an agent.spawn with no model to opus. The guard tokenizes the command as Bash would — quotes removed, each $(…), backtick, sh -c or eval string a command of its own, heredoc bodies skipped — then matches each command's argv, so quoted text never trips it and quoting never hides a command.
  • window clock — pipes the session's five-hour rate limit through statusline --window (below).
  • band and capture — the sandman shift above the prompt, corrections and repeated instructions to the trail, and /shift, /docket, /trail.

Marketplace

The repo is the local marketplace jgeschwendt (.claude-plugin/marketplace.json), listing perpetual and monitor (skills/monitor). An install is a versioned copy under ~/.claude/plugins/cache/, not the trunk; mise run link reports differs: until it is updated.

Statusline

The claude-home crate; segment rules in src/statusline.rs.

Fable 5 (fast · low) ██████████▎░░░░░░░░░░░ 52% ≈46m · $1.20 · 5h 31%† ↻ 10:50pm
  • the line — model, non-default mode flags, context use against the auto-compact threshold with an ETA, session cost, the five-hour limit and its reset. Every segment is conditional.
  • installed outside target/ — mise run build installs ~/.local/bin/statusline, which settings.json runs; mbx redirects target/ into its cache and gc prunes it. A source change is live only once rebuilt.
  • the window clock — each tick carrying rate_limits writes $XDG_STATE_HOME/claude/window.json atomically, under a directory lock, for sandman shift clock. Monotone: a window behind the stored one, not resetting within 6 h, or with a percentage outside 0–100 writes nothing.
  • statusline --window — that write alone, the only other way in; the mod uses it, so one rule and one lock cover every writer.
  • the log — ~/.claude/logs/statusline.log, each tick's payload or error, overwritten.

Gate

hk's pre-push hook (hk.pkl), one step.

The stele gate, clippy with warnings denied, cargo test — units in src/; tests/ drive the statusline, link, /delete, /dissolve and monitor-github — then the mod's own suite.

ci.yaml runs clippy, the tests and the stele gate on push to main, pull requests and the merge queue; never stele build, the lock's sole writer.
